# 屹立工作台 V3：从巡视项目到接手作业

本轮交付一个可点击、可改变条件、可刷新接续的中文原型。首要任务：同事能找到需要关注的项目，把范围明确的工作交给智能体，回来后判断实际进展。资产组合是完整可玩的支线，不是首页的主任务。

## 打开工作台之后

| 所在位置 | 人的动作 | 界面实际改变什么 |
|---|---|---|
| 顶层详细仪表盘 | 左右切换项目 | 留在观察模式；显示项目名、服务状态与最近业务产出。服务在线而产出未知时，两项分别呈现。 |
| 顶层模式切换 | 点四格键；再切回单项目 | 显示位置稳定的项目格，切回时记住当前项目。切换方式要看得出来，不靠隐藏手势。复用现有项目；不为凑四格捏造生产项目。 |
| 项目总览 | 点销售助手的项目格 | 直接进入销售助手操作台，不先放大仪表盘。格内用轻量入口标识点击去向。运行异常与正在改造可以并存；不用无分母的进度条。 |
| 项目操作台 | 点部署与迁移、画像连接、知识资料、画像对照或项目记录 | 直达对象；若有异常，标在对应入口，进入后先看到具体异常。其他项目只展示其实际工作面。常用目的地三次交互内找到，不把授权算作多余点击。 |
| 迁移准备 | 选择隔离服务器、已有本地凭据引用及范围，检查条件 | 显示哪些已检查、哪些未检查。目标不可达时不能授权；换目标、凭据或范围后旧授权失效。原型仅提供演练引用，不让同事上传真实私钥。 |
| 智能体交接 | 查看并复制当前上下文 | 同一出口随对象和动作生成提示词，包括项目索引、作业编号、目标、范围、授权边界及回执要求。允许补充说明；编辑文字不改变结构化授权。复制不是派发，更不是执行。 |
| 回到同一件作业 | 刷新页面、打开记录或提交模拟回执 | 对照当前作业和配置验证回执；错误回执不推进。显示最后一个已确认事实、未知项、下一项可做的事；旧目标的结果保留为历史。 |

## 最重要的两屏：交给智能体之前与之后

以销售助手迁移为例。交接前，主要版面只保留目标、凭据引用、范围、检查结果和当前操作。提示词框靠近复制按钮；索引、Skill 与维护文档供智能体继续读取，不把交接指南摊成整页小字。授权是独立事件，未取得的权限不得写成已获准。

交接后，再打开页面应看到同一项作业，而不是从头填写。例如：“数据库已迁移；团队物料是否完整尚未确认。”主操作此时是核对物料，不是重新迁移。服务启动但测试账号读不到物料，仍显示业务验证失败。只有匹配回执才可显示已接手；只有对应的业务验证才可显示“模拟迁移：业务检查通过”。

## 资产支线：可组合，不自动接入

四宫格下方保留资产池。支持多选、拖到项目、撤销；也提供不依赖拖动的选择方式。例：把“方舟 → 飞书画像”放到销售助手，底部显示目标与所选资产，允许修改拟议用途，并复制“核对同源、字段和当前消费情况”的任务上下文。移除资产、换目标后提示词随之更新。没有证据的用途标为待评估，不生成虚构接入关系。无需推荐引擎、真实资产扫描或部署。

## 工作方式与范围

1. 使用同级新目录，不覆盖 V1/V2，不占用其运行端口。艺术风格由设计者决定，草图约束的是空间关系与交互，不是黑底、边框宽度或竖排字。关键判断和下一步用正常字号；颜色不能独自表达状态。
2. 先贯通“巡视 → 四宫格 → 工作面 → 交接 → 离开再回来”，再接入 V2 已有领域逻辑，覆盖其余工作面与资产池。模拟调试条件改变输入或回执，不能直接指定页面结论。不得用静态成功页、教程菜单或让员工手抄上下文来替代交互。
3. 继承[八条业务剧本](WORKBUDDY-WORKBENCH-UI-BRIEF-20261106.md)及[V2 验收记录](../workbench-prototype-v2/ACCEPTANCE.md)中的行为边界，而非原布局。保留接手、运行观测、失败恢复、凭据维护、迁移、知识更新、调度、资产利用；既有资产利用验证不被拖放演示替代。
4. 不连接生产、不读真实凭据、不执行真实迁移。不做费用中心、通用备份中心或上下线管理。真实 WorkBuddy 接手与隔离环境迁移另行验证，不用模拟通过代替。

## 怎么判定这版值得接后端

- 导航：请未参与设计的同事分别“看某项目运行状况”和“处理某项目的画像连接”。不提示用哪个入口，记录第一下点击、是否绕路及实际步数；若仅作者走查，标注未做新人验证。
- 业务：同一作业演示复制后仍待接手、错回执被拒、匹配后才推进；换配置让旧结果失效；刷新能恢复当前状态；结果未知先核对，不重复迁移已成功的数据库。其余业务场景复跑对应回归。
- 智能体：用全新 WorkBuddy 会话读取已复制的内容，核对是否能打开索引、说对项目与下一动作、区分模拟和授权。不能访问的地址或尚无的 Skill 如实说明。
- 交付：可运行入口、源码、接手索引、实际点击记录；同一作业的准备、待接手、接续三种画面。分别列出原型验证、真人试用、真实智能体验证和未接入能力。不以测试条数代替上述结论。
