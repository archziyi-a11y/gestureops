# 桌面窗口

本机桌面壳，不是跨机器安装包。复用工作台 5185 服务及 `%LOCALAPPDATA%/YiliWorkbench/spatial-demo`，不迁移业务数据。

首次安装：在本目录依次执行 `npm ci`、`npm run setup` 下载桌面运行时。日常启动仍用上级 `start-workbench.ps1`；原桌面快捷方式无需改动。`-Browser` 保留浏览器入口，`-ServiceOnly` 只启动服务。`npm test` 执行桌面关闭与服务存活测试，不触发业务写入。

关闭按钮隐藏至托盘，双击托盘或再次启动恢复同一窗口。托盘退出会停止系统通知，但后台 Node 服务保持运行。

## 自启与系统提醒

2026-11-16 增加 Windows 通知及当前用户登录后自启。首次启用以 `electron . --enable-autostart` 启动一次；以后遵循托盘“登录 Windows 后启动”的设置，不会每次启动强行重新启用。自启传入 `--background`，不主动弹出窗口。必须登录 Windows 且电脑保持唤醒，才能持续运行；不承诺关机、休眠或注销时检查。

桌面主进程每 5 分钟读取 `/api/operations-reminders` 和 `/api/card-observations`，与窗口显示无关。只消费现有观测，不自动修复、重跑或发送业务消息。问题的原始时间仍以工作面证据为准，不代表通知时刚发生。

同一问题持续存在时不重复弹窗；明确恢复后复发、或升级为严重问题重新提醒。多个新问题合成一条，不发送客户正文、凭据及原始错误。点击通知打开对应工作面（多项或卡片问题打开总览）。读取失败或卡片缺失不当成恢复；计数、余额小幅变化不重新弹窗。操作提醒使用问题 ID 与首次观测时间，卡片使用卡片 ID，因此同卡片持续异常期间更换非严重原因不会单独再弹。

去重状态保存在 `spatial-demo/desktop/notifications.json`，先保存再投递，优先防重复；系统拒收或程序在投递间隙退出时，可能不弹该次通知，站内问题仍保留。失败记录在同目录 `notifications.log`。去重文件损坏时停用通知，不清空重发。Windows 勿扰、通知权限可阻止横幅；托盘“测试系统通知”用于检查。关闭窗口继续提醒；选择“退出提醒程序”则停止通知。

托盘提供系统通知开关、自启开关及测试按钮。通知开关重新开启时会提醒暂停期间新增且未通知的问题。无需更改机器级启动设置。开始菜单快捷方式注册应用标识，注册表 Run 项仅属于当前用户。

界面采用独立 WebContentsView，外链在系统浏览器打开，不向网页开放 Node 或进程控制权限。原生窗口按钮与深色标题栏配色一致，保留系统缩放和最大化操作。

验收边界：窗口关闭不停止服务、不改数据目录；重复启动不新建服务；外部链接不得在有权限的本地页面中打开。启动失败应显示错误，不能终止未知的端口占用进程。
