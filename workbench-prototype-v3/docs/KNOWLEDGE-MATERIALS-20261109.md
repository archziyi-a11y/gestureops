# 知识与物料实际接入

## 目标与范围

员工维护两个不同对象：团队物料供人复制/分享，模型知识供回复检索。团队物料不自动成为知识。上传、核对、发布、撤回、试问应在工作台完成，不退化为仅复制智能体任务。

本轮本地实现知识版本库，复用既有语义模型；不自动部署或切换生产灰度。检索采用关键词候选与模型语义选择，明确不是已经接入向量数据库。扩展向量索引不能改变来源、版本、适用范围和撤回合同。

## 业务约束

- 保留原始文件、解析块和来源；表格保留表头及所在段落。没有解析出的内容不编造。
- 上传仅生成草稿；用户核对内容和适用范围后显式发布。替换绑定被替换版本，过期草稿不得覆盖新版本。
- 待确认年度、价格以及内部管理材料不得自动进入可检索知识；范围由审阅决定，不靠关键词替代业务判断。
- 发布原子切换版本，撤回生成新版本；试问报告实际使用版本及来源，不代表生产已加载。
- 团队物料读写复用现有 API；写成功和手机同步分开。结果未知不自动再次提交。

## 关键失败与验收

### 双栏试问与 RAG 体检（本轮）

目标：同一问题、范围与模型，分别展示不使用知识库和使用知识库的回答，保留检索版本、实际送入回答的片段和引用。不预设 RAG 胜出；一侧失败保留另一侧结果，旧问题的回答不得冒充新一轮结果。不自动重试模型；一次对比至多三次请求（基线、语义选择、增强回答）。

回答阶段增加独立的整块预算，不改分块、嵌入或发布索引。验收覆盖资料不泄漏至基线、超预算、非法引用、单侧失败、重复点击、宽窄屏。真实销售题集未提供前，仅报告合成回归，不宣称真实命中率改善。

解析失败、空文件、重名更新、重复上传、并发发布冲突、模型不可用、未知来源ID、撤回后仍命中、表格断上下文、跨年度引用。先离线测试及浏览器替身验证，再做授权的真实模型验证。测试不向生产库写资料。

## 已实现（2026-11-09，本机 Asia/Shanghai）

- 模型知识：TXT/MD/DOCX 上传、原文件留存、重复识别、段落与表格解析、人工审核、可选模型整理建议、原文来源校验、同名明确替换、发布及撤回、试问。发布同时校验资料修订号与知识库版本，避免覆盖他人审核结果。
- 单文件 8 MiB、单块 12,000 字、最多 2,000 块；过限明确拒绝，不静默截断原文。年度和适用学校/项目由审阅人确认，未指定查询范围只检索通用资料。
- SQLite FTS5 候选检索加模型语义选择，支持中文；语义候选有 80 块/60,000 字符边界，覆盖不足在页面提示。它是可用的轻量检索增强链路，不宣称大规模向量检索已完成。
- 团队物料：现有生产 API 的列表、搜索、类型筛选、文本/链接/图片上传与预览。页面不代理未支持的删除/改名。回执区分成功、明确拒绝、结果未知；未知不自动重发。手机同步需另验。
- 两种内容独立，团队物料不会自动进入模型知识。

## 运行与接入

工作台入口为 `#/p/sales/w/knowledge` 和 `#/p/sales/w/materials`。本地知识存于 `STATE_DIR/knowledge/knowledge.sqlite3`，不是仓库可公开文件。

模型连接沿用 mktci 现有配置，不新建密钥。模型只在点击语义整理或试问时调用。语义失败披露关键词回退；回答只接受当前检索片段的引用 ID。引用合法不等于语义正确，仍需真实业务问题验收。

销售助手运行时增加 `SASALELE_KNOWLEDGE_DIR` 显式接入点；未配置时沿用原静态知识，原灰度开关不自动打开。已配置后，以该发布库为准，包括空库和撤回结果，不回退静态库复活旧知识。本轮未部署生产，也未搬迁历史 408 条知识。

团队物料复用服务器端固定团队配置文件；浏览器不接收 token、不允许指定任意服务地址。服务仅绑定 localhost，并检查 Host、Origin。知识接口与物料接口禁止跨站写入。
