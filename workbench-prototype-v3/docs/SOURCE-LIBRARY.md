# 销售知识源文件库

## 目标与约束

## 本轮体验调整

目标：按知识资料、回答调试、团队物料分离工作面。统一由原件库上传；创建知识草稿后直接打开文档；已有知识文档可继续管理。保留原件、已有发布记录、来源关联及生产发布接口，不迁移或删除数据。

关键失败场景：解析失败保留原件；未确认不可发布；路由跳转必须打开对应文档；内部参考不直接生成草稿；保存草稿不调用模型、不发布。验证以原件上传→草稿→保存→发布→带范围试问及三工作面切换为准，使用离线模型替身，不执行生产发布。

已验证：源文件 Python 测试 2 passed；source-library 浏览器/API 回归通过；knowledge-api 完整链路通过（含未审阅草稿可保存但不可发布、发布后试问、提示词版本隔离）。桌面及 390px 窄屏截图已检查。测试使用独立临时资料库，物料接口使用替身，没有改变真实归档与发布内容。

保留用户提供的原件，追踪来源、用途、整理稿与知识发布去向。归档不等于发布；原件按 SHA256 去重且不可覆盖。业务规则与知识原料可送去整理，提示词参考、内部参考、实现记录须先审阅用途，不能默认进入对客知识。

入口：销售助手 → 知识与物料 → 知识资料。原件与知识草稿/发布记录在同一工作面下管理；回答调试与团队物料为另外两个工作面。总览的「销售知识资料」资产卡可查看统计、进入文件管理并参与上下文组装。旧 sources 地址仍可访问。

## 存储与流程

- 私有目录：`<STATE_DIR>/knowledge/source-library/`，不通过静态文件服务器公开。桌面启动器使用 `%LOCALAPPDATA%/YiliWorkbench/spatial-demo`；直接启动且未指定 STATE_DIR 时才使用仓库 `data/`。必须先核对当前实例，不能将两处混用。启动与恢复见 [运行说明](OPERATIONS.md)。
- `originals/<sha256>/<原文件名>`：原始字节副本；`sources.sqlite3`：来源、用途、父原件/前版、处理记录、知识文档关联。
- 上传支持 TXT/MD/DOCX/JSON/PY/PDF/XLSX/CSV，最大 8 MB。TXT/MD/DOCX 可进入现有知识整理流程，其余保留原件供下载和后续处理。
- 新版上传时选择关联原件/前版，生成独立哈希项；相同内容只追加来源，不覆盖原用途与关联。
- 「创建知识草稿」解析原件、创建或关联同内容知识文档并自动打开；已有文档显示「打开知识文档」。该动作不调用模型。编辑页可保存未审阅草稿，模型处理另用「生成整理建议」。发布前必须确认内容和范围并保存；已有文档保持原发布状态，不因归档重新发布。
- 发布后保留当前文档，可「用这份资料试问」带入学校/年度范围；检索仍针对该范围下的已发布知识，不强制只检索这一份文件。业务提示词对比只使用填入的测试文本，不自动加载手机聊天/画像。
- 预览只显示文本前 100 KB，二进制文件下载查看；全部下载前复核哈希。原文仅以转义文本显示。
- 时间由本地服务时钟记录为 UTC，界面转换为北京时间。

## 首次归档

发布版导入接口：`scripts/import_sales_sources.py <manifest.json> --library <本地资料库目录>` 仅处理显式清单，不搜索下载目录或聊天缓存。清单是 JSON 数组，每项包含 `path`、`purpose`，可选 `note`、`parent`；相对路径基于清单所在目录，`parent` 是已归档原件 ID。用途须符合资料库现有分类。清单与真实原件保存在仓库外，不随源码提交。以下是历史归档记录，不是现行接口的默认输入。

`scripts/import_sales_sources.py` 仅处理用户清单及明确来源：33 份去重材料、4 个重复微信来源，缺失 0。原位置不移动、不删除。

漏列的四份原料由历史知识条目的 source.file 反查确认：北京各区高中全名单、北京美术特色高中名单、市场课程顾问作战手册、戏美方向院校专业汇总。私有归档与微信缓存副本哈希相同。

录音转写、接待演练整理仍为内部参考；3chat 材料仍为提示词参考，未当作可直接执行的 Skill。历史代码/文档是归档时点快照，不自动跟踪后续源码变化。机器路径与逐文件哈希保存在私有 `IMPORT-RECEIPT.json` 中。

## 验收重点

### 只读维护检查

先核对当前工作台进程的启动目录和 STATE_DIR，再关联原件库。source snapshot 会构造 SourceLibrary，可能创建目录与表，不能只因接口名称含 snapshot 就当成无副作用探针；原文详情、整理和发布各有独立读取或写入范围。

原件完整性只核对必要元数据、大小和哈希，不输出正文。数据库使用正常只读事务并考虑并发；不能仅因当时无 WAL/journal 就对活动库使用 immutable=1。若锁或 sidecar 行为超出授权，记录限制或使用已授权的一致性快照，不绕过锁。归档完整、整理关联、发布和实际业务消费分列判断，未关联不证明其他系统未使用。

原件字节不变、重复不增项、目录穿越拒绝、用途限制、送去整理不发布、版本关联、修改冲突、下载哈希、页面切换与窄屏布局。归档和页面测试不调用模型，不发布生产知识。

历史离线验证：Python 源文件库测试 2 passed；真实浏览器验证上传去重、原件下载字节、预览、关联草稿、用途阻断、资产统计及桌面/390px 窄屏布局通过。2026-11-11（北京时间）现用5185实例恢复后读取33份，其中7份待整理，属于当次观测，不是当前固定数量。历史知识文件是否在其他系统发布，不由本库未关联状态推断。
