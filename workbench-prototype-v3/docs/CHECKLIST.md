# 验收与接续

## 按改动选择验证

| 改动 | 必查 |
| --- | --- |
| 文档 | 链接存在、命令与代码一致、历史与当前分离 |
| 详情排版 | 完整页面样式下桌面/窄屏截图、长文字、空值、折叠与关闭返回；不能只测组件样式 |
| 卡片状态 | 正常/失败/部分/未知、历史/当前、单对象/全范围、零/缺失；详情与组装上下文一致 |
| 写入接口 | 对象与权限、重复提交、结果未知、部分成功、刷新回读；测试替身同步 |
| 数据迁移 | 备份、原件哈希、记录与关联、当前实例API回读；文件存在不等于接通 |
| 远端部署 | 授权范围、版本、重启结果、业务验收与回退依据；不可用本地测试替代 |

相关离线入口位于 `tests/`：`workspace.mjs`、`maintenance-context.mjs`、`dashboard-details-browser.mjs`；源库为 `tests/test_source_library.py`。先读测试，确认是否启动服务、写临时目录或依赖真实接口；不要无差别运行所有测试。浏览器测试需配置 BUNDLED_NODE_MODULES 指向已安装的Playwright依赖目录。

## 新智能体接手试验

只给 AGENT-START.md 与一个具体目标，不提供旧聊天。检查它能否找到真实入口、核对实例与数据、继承授权范围、识别共享依赖、区分未知/失败/部分成功，并交付下一位可接续的记录。只诊断任务以诊断完成验收，不能暗中改成必须修复。
