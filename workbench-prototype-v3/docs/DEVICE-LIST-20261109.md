# 工作机列表重组

## APK 批量更新与工作端兼容（2026-11-09）

目标：拖入新版 APK 后检查包身份/签名/版本，展示目标工作机，确认后发布登记并逐机下发。保留单机更新。不自动卸载、清数据或升级方舟工作端。

Owner 已确认截图中的 1.0.0.703 工作端无法自动更新；点击更新提示先升级手机端方舟工作端。仅此版本按已知不兼容处理，不把所有安装超时或所有其他版本归为同一原因。前后端均检查，批量默认排除旧版及离线设备。

授权提示读取本地团队配置的 expires_epoch，仅输出有效期，不返回凭据。它反映本期配置有效期，不代表实时服务器撤销状态。清单上显示到期日，时间为北京时间。

失败边界：错误包/签名不符不得发布；本地上传检查不产生远端写；确认批量才发布并下发；逐台保存回执，结果未知时停止后续，不自动重试。验证使用替身，未授权的真实手机不会作为测试目标。

实现结果：5185 服务已接入本地 APK 接收/签名检查、显式确认后的 OSS 发布/登记与逐机安装接口。批次保存在 data/work-device-batch.json，重启不自动续派；APK 与发布阶段保存在 data/device-releases，静态服务禁止访问 data。发布依赖本机 Android SDK、现有 v35 签名基准 APK 和方舟 SDK；缺失则检查失败，不降低为文件后缀检查。现有团队配置到期日为 2027-01-12（Asia/Shanghai）。

验证结果：Node 单机/发布/批次替身测试通过，Python 8 项通过，浏览器旧版提示、到期提醒、实际拖放事件、设备排除、确认与回执通过（API 为替身，含桌面/移动视口）。真实本地 HTTP 上传 v35 APK 验证通过：com.example.sasalele / versionCode=35 / 64233023 字节 / phase=inspected；未向远端上传、更新登记或派发。真实批量手机安装效果仍待用户实际使用验证。打开工作机页面自动读取最新清单，保留手动刷新。

## 真实下发接入（2026-11-09，后续阶段）

目标：页面选择方舟已登记的销售助手安装包，针对单台设备安装或覆盖更新；不再生成智能体代办任务。保留后台团队鉴权，不新增逐机凭证维护。

约束：不卸载、不清除手机数据、不升级方舟工作端。点击确认才发真实安装指令。服务端先保存提交记录，受理不代表安装成功；网络结果未知不自动重发，刷新后仍能查到记录。平台旧应用名回报不能证明本次版本已安装。

核实差异：现有 Android ProvisionWorkDeviceActivity 通过手机文件选择器导入 JSON，且 exported=false；安装接口不等于团队配置下发。本轮不能声称全自动配置完成。新机安装后仍需既有管理员导入步骤，远程配置需补客户端接收能力。

验收：离线替身覆盖单设备下发、重复点击、超时、重启恢复和应用登记变更；浏览器核对选择与回执。真实注册应用只读核验，不自动向生产设备试发。

本阶段结果：本地 5185 服务已接入真实方舟安装接口；已读到 SASALELE v35 登记。安装包选择绑定登记指纹，提交时重查设备在线/未删除及登记未变。回执保存至 data/work-device-actions.json；同设备同包已受理或结果未知时不重复下发。安装状态仍读取平台回报，不推断当前手机版本。该记录服务按单进程运行，不支持多个服务进程共享写入同一状态文件。

验证：Node 下发存储 6 项、Python 适配器 5 项、清单 11 条断言、销售工作面 13 条断言通过；真实浏览器用替身接口完成安装/更新/回执流程；本地 API 跨源提交返回 403、无效参数返回 400。只读真实目录和设备字段通过，未向真实工作机发送安装命令，真实手机安装验收尚未执行。

未完成项：新工作机团队配置自动送达/导入，需要补齐客户端配置入口；本阶段没有实现，也没有改回逐机签发策略。

页面刷新：首次打开和从其他页面返回工作机页时，自动读取清单及下发记录一次；搜索、弹窗、普通重绘不触发重复读取。在途请求合并，失败保留原结果与时间，手动刷新入口保留。浏览器替身验证首次进入、搜索不重读、返回重读和手动刷新通过。
