# 销售总览自行复查状态

目标：不再要求用户先进入工作机或运行与排查刷新，上层卡片才能更新。

原因为总览只读取持久化提醒，工作机自动查询仅在详情挂载；读失败只在同一操作再次成功时解除。

总览读取提醒前复查工作机；有历史模型配置读取/连接测试失败时，只重做对应只读查询；余额未查、到期或失败超过一分钟时查询。服务端一分钟缓存、并发合并，各源失败互不阻塞结果处理。后台观察不写成人工维护作业。

必须保持：不重做安装、配置保存、重载或任何写入；成功只解除同对象同操作的读故障，不能解除未知写入；查询失败保留旧工作机数量但不显示成新观测。没有故障也不称全系统健康，卡片展示在线数和余额。

验收：不打开子页面即可解除恢复后的清单/连接读故障；重复读取合并；失败保留旧值；写操作故障不被清除；余额查询不调用生成模型。

验证结果（2026-11-11）：sales-overview-refresh、operations-reminders、sales-live-facts 测试通过，server.js 语法及范围内 diff-check 通过。本地 5185 服务已重启，沿用原状态目录。真实浏览器直接打开总览、不访问子页面，卡片显示“工作机 15/17 台在线 · 模型余额 ¥14.76”。工作机接口观测时间为 2026-11-11 09:18:20 +08:00；该读数是当次观测，不是永久健康结论。历史读故障恢复由离线回归覆盖，未人为制造生产故障。
