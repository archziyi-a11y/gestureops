# 员工使用指南

本指南按 2026-11-11 工作区版本整理，介绍从总览进入常规维护的使用路径。

## 打开工作台

在配置了工作台的 Windows 电脑上，由员工打开现有工作台入口；本机默认地址为 <http://127.0.0.1:5185/#/grid>。未启动时按[运行说明](OPERATIONS.md)使用启动器，不另开默认 5183 实例尝试“找回数据”。本机地址指打开浏览器的这台电脑，不是远端服务器。

从“项目总览”进入销售助手、Prism 或对接表 Agent。卡片状态要连同详情的观测时间、数据来源和范围看；历史调查、文件存在、服务运行都不等于业务完成。

发布、删除、下发和发送会影响实际业务。**必须**核对本次操作的账号、设备或目标环境，避免改错对象；已明确的常规操作不需要反复确认。

## 给销售助手补充资料

入口：销售助手 → 知识与物料 → 知识资料（`#/p/sales/w/knowledge`）。

1. 在“原件”页选择或拖入文件，填写来源及用途。最大 8 MB；支持 TXT、MD、DOCX、JSON、PY、PDF、XLSX、CSV。结果是原件归档，不是知识发布；重复内容不重复归档。
2. 选择原件，查看用途、来源和关联状态；“下载原件”取回原文件。“保存资料信息”保存备注等信息，不替换原文件字节。
3. 对适合进入知识库的 TXT、MD、DOCX，点击“创建知识草稿”；已关联的文件显示“打开知识文档”。其他格式可归档，不保证可直接整理。内部参考、提示词参考等不能默认当作对客知识。
4. 在“知识草稿与发布”编辑并保存。创建、保存草稿不调用模型；“生成整理建议”是另外的模型处理动作。
5. **必须**审阅内容、确认适用范围并保存后再发布，防止错误资料进入回答范围。以发布返回结果为准，不以草稿保存成功代替。
6. 发布后可用“用这份资料试问”进入带学校、年度范围的调试。检索对象是该范围内已发布知识，不保证只引用当前文件；试问结果不证明手机端已消费新知识。

同一工作面还有“回答调试”和“团队物料”：前者用于试问、提示词对比，后者用于团队共享物料管理。业务提示词对比使用填入的测试文本，不自动读取手机聊天或画像；测试修改不等于实装。物料删除等真实管理动作须单独核对对象，空列表不自动说明故障。

## 排查销售助手或工作机问题

销售助手 → “工作机”查看设备状态和回执；设备在线、更新已下发、安装完成是不同结果。看业务是否正常，先打开销售助手卡片详情；维护连接、查询余额或做基础修复，再进入“运行与排查”。余额可读不等于回答生成正常，近期无请求也不等于故障。

需要部署、升级或搬迁时进入“部署与迁移”，交由维护人员核对环境与恢复资料。准备任务、复制交接内容不代表迁移执行。不要使用旧 README 的模拟目标和模拟回执作为生产操作步骤。

## 查找 Prism 教学资料

入口：Prism → 教学资料（`#/p/prism/w/library`）。先看“已归档笔记”和“已归档图片”，选择已有归档或批次查看结果。笔记提供本地归档浏览；图片批次可“刷新批次”“检查媒体完整性”。清单数量不替代图片解码检查。

“验证整批（本地隔离）”是本机临时库验证，不是发布。**必须**满足页面限定的 1–100 张、累计不超过 100 MB 才执行整批验证；超过范围应交维护人员拆分，否则不能获得整批验证结论。“验证首张图片”只证明该样本。

确有采集任务并获授权时，才展开“准备下载图片”或“准备下载笔记”：前者选择最近两天或指定起始日期，点击“下载新增图片”；后者选择科目目录，点击“下载并整理笔记”。这些按钮会实际下载，不是预览。图片沿用四个已配置教研群；笔记沿用三个科目目录，普通附件仅保留目录信息，不扫描整个飞书空间。

提交后区分正在采集、已完成、部分完成、失败、结果待核对；手动任务和定时任务记录分别查看。下载整理不等于 Prism 发布，单群结果不代表全部群。日期选择也不一定等于实际读取窗口，待补恢复可能前推，须查看回执范围。

Prism 首页的“打开 Prism（本地）”指向本机 4173，链接存在不保证服务已启动。“访问与权限”只准备指定账号、资源的核对任务，不授予权限；“部署与服务”准备排查任务，未采集的状态不能当成健康。教师实际可用仍需指定身份找到并打开资料的证据。

## 查看对接表批次与待补

入口：对接表 Agent → “账号与表配置”“批次与待补”“运行与排查”。范围是品宣市场对接表，不包括入学表及其他私域同步。

1. 在账号与表配置核对工作账号及绑定；在批次与待补选中目标批次，查看行结果和个人表、总表分侧状态。
2. 需要提醒补充时点击“追问待补项”，先取得当前缺项预览。预览会读取飞书，但不发送卡片、不写表。
3. **必须**核对预览的批次、账号、原会话和缺项后，才点击“确认发送卡片”。它会真实发到批次原会话，不能从此入口任意指定收件人；对象不对时取消。
4. 飞书接受不等于员工收到或填写成功。员工在原会话点击卡片选择记录并补充后，重新读取批次核对结果。发送未知或接续绑定未确认时不要重复发送。

该发送接口已实现，但维护记录仍标明真实卡片发送和员工回复续填待验收，不应承诺端到端已验证。额度不足或读取失败时停止，不能拿旧缺项发卡。

“运行与排查”提供配置读取、测试、保存及单独确认重启。测试不发业务消息、不写表、不调用模型生成；保存不自动重启，重启完成也不证明写表恢复。配置操作由获授权维护人员处理。

## 拖卡片交接问题

在总览把相关卡片拖到左侧“查看详情”看依据；拖到右侧“加入处理”放进“本次处理”。详情内也可用“加入本次处理”或“加入上下文”。

移除无关卡片，点击“查看上下文”，检查对象、现象、范围与未知项，再“复制处理任务”交给实际接手人员或智能体。可编辑预览，但不要添加密钥和客户正文。复制只进剪贴板，不自动启动智能体、不执行修复。

项目组装中的“保存草稿”仅保存本地组合；“预览与复制”生成交接内容，不创建远端业务系统。

## 到哪里查操作结果

顶栏“作业记录”（`#/records`）查看已接入的维护动作；各项目首页“维护记录”查看本地准备、历史交接等记录。两者不是完整生产审计。旧模拟记录不作为真实完成证据；只读查询也不一定新增作业。

区分成功、失败、部分完成、结果未知、下发待验。结果未知先核实，不直接重试；后续记录或界面失败不能抹去已知业务成功。报障提供入口、脱敏对象/批次编号、原始提示和时间，不发送密钥或聊天正文。

页面标注北京时间的时间按 Asia/Shanghai 阅读；本地维护时间来自本地服务端，不等于源消息发生时间、真实入库时间。统计窗口以页面给出的起止及来源时钟为准，缺失时保留未知，不自行推算耗时。
