# 上下文反馈

- INPUT 明确静态注册与实时观测的区别、只读 health 日志边界、禁止重启和仅限报告目录写入，足以安全启动诊断。
- 建议生成器为每个对象提供可审查的实际入口定位方式、health 路径与其仅证明什么，特别是 `AFTB-Pilot-Observation` 不在旧双 Bot 汇总中；保留运行时重新核验要求，不能把这些字段当实时事实。
- 建议提供工作台进程身份与只读快照的定位及副作用审查入口，而非仅给端口。端口监听不能证明具体实例或页面可用。
- 为每条服务指向允许只读的脱敏回执索引、字段与时间语义，区分服务存活、HTTP 可达、调度执行和业务完成；缺失时明确未覆盖，不以 health 代替回执。
- 建议标记历史审计的时间窗口与证据范围，保留历史错误作为待复核线索，不生成当前故障结论。上述为上下文及手册修订建议，未改共享文档或放宽权限。
