# 卡片接手上下文反馈

## 可直接找到

来源索引足以定位本机计划任务和 CSV 元数据；仓库搜索任务名可找到卡片采集代码、同步脚本、注册脚本及历史观察。卡片明确时区、观测时刻和元数据边界，足以避免把旧观察当成实时状态。

## 缺失与歧义

卡片未指向实际维护脚本、注册脚本及部署说明；现有部署说明的按账号手工导出与定时任务全账号同步不同，容易误认为同一流程。卡片未提供任务执行账号、计划周期、上次运行时间、下次运行时间或新鲜度阈值；这些可从本机只读核实，但不能从旧卡片推断当前值。全账号范围是否经业务授权、消费方和验收标准无法从本轮证据确认。当前不需要主协作者补充才能完成只读调查；要判断授权范围或端到端验收时才需负责人确认。

## 建议的最小上下文补丁

在来源索引追加仓库路径 `project/modules/qm-sales-assistant/tools/sync_portraits_local.py`、`project/modules/qm-sales-assistant/tools/register_portrait_sync.ps1` 和 `workbench-prototype-v3/src/domain/business-card-observations.js`；注明注册脚本会首次真实同步并覆盖注册，须另授权。说明当前任务参数范围应实时核对，部署 README 手工按账号导出不是此任务的运行手册。不要把历史任务账号、时间或未批准阈值固化为实时事实。
